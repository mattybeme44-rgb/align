How this measures

Two signals are compared sample by sample: a reference and a measurement. In Generated mode the reference is the exact noise or sweep this app plays, so a single microphone is enough. In Loopback mode the reference is whatever arrives on input 2, which is the true dual-channel method and needs a two-input interface.

The averaged cross spectrum gives the transfer function — magnitude, phase and coherence — and its inverse transform is the impulse response, whose peak is the delay. Delay compensation removes that delay from the phase so two systems can be compared for alignment.

Levels read dBFS by default. A calibrated measurement microphone comes with a sensitivity figure, and entering that offset in the Analysis card turns the input readout into dB SPL — the sound pressure in the room rather than a fraction of full scale. Without a calibrated mic the offset means nothing, so leave it at 0. Measurements stay relative either way, which is what alignment work needs.

Phone microphone — no interface needed: set Input to iPhone microphone and leave Reference on Generated and Measurement input on Input 1. The speaker and mic are one device, so keep the level low or use headphones to avoid howl.

USB-C interface on iPhone — connect the interface, set Input to USB audio interface (or pick it under Detected inputs) and press Start in Safari. iOS routes audio to the last connected interface, so the app records from it instead of the phone microphone. Watch the two level meters above to see which input your mic is on, then pick that one as the Measurement input. Feed the interface's second input with the reference signal and select it as the Reference input for the dual-channel method. If the meters stay still after plugging in, press Restart: iOS keeps the old audio route until the stream is reopened. Set the interface to 48 kHz and enable phantom power for a condenser measurement mic.
